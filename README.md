# 고요한 밤 (Silent Night)

정전된 집에서 선물 다섯 개를 찾아 현관으로 탈출하는 모바일 세로형 공포 게임.
브라우저만 있으면 되고, 설치할 것은 없습니다.

## 규칙

- 화면 **아무 데나** 손가락을 대고 끌면 그쪽으로 걷습니다. 걷는 쪽이 곧 손전등 방향입니다.
- 오른쪽 아래 **달리기 버튼**을 누르고 있으면 뜁니다. 체력이 있는 동안만.
- **손전등 버튼**으로 불을 켜고 끕니다. 배터리는 계속 닳습니다.
- 선물은 **방울 소리**로 위치를 알립니다. 가까울수록 빠르고 높게 울리고,
  좌우 위치는 스테레오로 들립니다. 세 칸 안쪽이면 어둠 속에서도
  붉은 기운이 어렴풋이 보입니다.
- 다섯 개를 모두 모으면 현관문이 열리고, 출구 방향에 화살표가 뜹니다.

## 핵심 규칙 하나

**불빛은 그것을 부릅니다.**

손전등을 켜면 8칸 밖에서도 들킵니다. 다만 빔이 향한 쪽에 있을 때 그렇고,
등 뒤로 새어나가는 빛은 그 절반 거리에서만 보입니다. 불을 끄면 그것은
두 칸 남짓 앞밖에 보지 못하므로, 모퉁이를 돌아 달아날 수 있습니다.
쫓길 때는 마지막으로 목격된 자리만 쫓아오고, 놓친 뒤에는 속도도 느려집니다.

가까이 있으면 숨소리가 들립니다. 어둠 속에서는 그게 유일한 경고입니다.

## 소리

배경에 흐르는 캐롤은 이 저장소의 `Christmas Time Again.mp3` 를 0.72배속에
로우패스를 걸어 오르골처럼 뭉갠 것입니다. 쫓기기 시작하면 필터가 열리고
속도가 붙으면서 곡이 원래 모습으로 깨어납니다. 탈출에 성공하면
`A Magical Evening Begins.mp3` 가 정상 속도로 재생됩니다.

발소리·심장 박동·방울 소리·비명은 모두 Web Audio 로 그때그때 합성합니다.

**이어폰을 쓰면 훨씬 무섭습니다.**

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구성과 HUD |
| `css/style.css` | 스타일 |
| `js/maze.js` | 미로 생성, 광선 추적(DDA), 시야 판정, 경로 탐색 |
| `js/game.js` | 이동·충돌·수집·추격 AI·긴장도 |
| `js/render.js` | 어둠, 손전등 가시 영역, 그것, 점프스케어 |
| `js/audio.js` | 배경음 가공과 효과음 합성 |
| `js/input.js` | 가상 조이스틱, 키보드 |
| `js/main.js` | 화면 전환과 루프 |

빌드 과정이 없습니다. ES 모듈을 그대로 씁니다.

## 로컬에서 실행

`file://` 로 열면 ES 모듈이 막히므로 정적 서버가 필요합니다.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

데스크톱에서는 WASD/화살표로 이동, 마우스로 조준, `Shift` 달리기,
`F` 또는 스페이스로 손전등을 켜고 끕니다.
